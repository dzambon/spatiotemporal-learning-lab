# Spatiotemporal Learning Lab

Hands-on notebooks on graph deep learning for modeling time series and spatiotemporal data.

The repository is a work in progress. Notebooks and explanations are being expanded and refined. APIs, examples, and structure may change over time.


## Installation

To run the notebooks locally, create an environment and install dependencies:

```bash
uv venv --python 3.11
uv pip install -e .
```

Then open the notebooks with your preferred Jupyter environment.
For Google Colab, follow the setup instructions provided inside each notebook.
